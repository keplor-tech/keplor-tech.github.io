# Keplor Visual Direction V3

This folder is a correction to the earlier design boards. Those repeated the same orb/space motif and therefore did not deliver the visual language shown in the user's Canva references.

## Start here
1. Read `KEPLOR_DESIGN_DIRECTION_V3.md`.
2. Open `/references/` to view the original Canva inspirations.
3. Review `/prototype/reference-aligned-hero-v3.png` and `/prototype/reference-aligned-full-page-v3.png`.
4. Open `index.html` locally to explore the simple responsive prototype.
5. In Codex, open the real Keplor repository and paste `CODEX_PROMPT.txt`.

## Important
- The prototype is plain HTML/CSS/JS and uses diffuse gradients, not a WebGL object.
- Internal navigation scrolls to real page sections. The contact CTA opens an email draft; configure the verified production contact address or wire a real backend before deployment.
- Do not copy earlier orb/planet concepts into this version.
- The V3 images are hand-built SVG mockups rendered to PNG; they are visual guides, not screenshots of a deployed or browser-tested production app.
