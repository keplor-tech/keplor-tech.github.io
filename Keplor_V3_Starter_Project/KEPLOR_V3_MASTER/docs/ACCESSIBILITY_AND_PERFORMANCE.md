# Accessibility & Performance

- Use semantic `header`, `nav`, `main`, `section`, `footer`.
- Maintain visible keyboard focus and meaningful link labels.
- Provide mobile navigation that works by keyboard and screen reader.
- Respect `prefers-reduced-motion`.
- Keep hero canvas lightweight, scale for device pixel ratio responsibly, and avoid unnecessary render work when hidden.
- Avoid layout shift; reserve space for visual elements.
- Verify color contrast and text sizes at all breakpoints.
