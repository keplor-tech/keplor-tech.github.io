# Motion System

- Hero arc: slow, atmospheric pixel intensity changes; no aggressive camera movement.
- Section reveals: small vertical displacement and opacity only; content must remain readable with motion disabled.
- CTA: subtle border/arrow movement, not oversized magnetic distortion.
- Navigation: restrained blur/opacity only where useful.
- Timing guidance: hover 160–260ms; button feedback 120–200ms; text reveal 450–750ms; stagger 60–100ms.
- Avoid fake loading screens, counters, scroll hijacking, parallax that harms reading, and animations on every item.
- Respect `prefers-reduced-motion`; use static arc or reduced animation.
