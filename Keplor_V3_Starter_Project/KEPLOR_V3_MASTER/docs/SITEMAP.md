# Sitemap

| Route | Purpose | Content rule |
|---|---|---|
| `/` | Brand introduction and project conversion | Clear positioning, services, process, industries, CTA |
| `/about/` | Mission, vision and approach | No invented team biographies or company history |
| `/services/` | Service pillars and engagement framing | Scope is project-dependent; no unsupported guarantees |
| `/features/` | Capabilities and principles | Do not present unshipped features as product features |
| `/blog/` | Field notes / insights | No fake articles or dates |
| `/testimonials/` | Client feedback | Empty state until verified feedback exists |
| `/careers/` | Future opportunities | No role listings unless approved and current |
| `/contact/` | Project inquiry | Clearly disclose if no real submission backend exists |

Public pricing is intentionally excluded.
