# Keplor V3 — Start Here

This ZIP is a **fresh starter project and master reference package** for the new Keplor V3 website. It is not a verified copy of the user's local repository, and it does not contain the original logo files or the original V3 HTML reference because those source files were not attached to this session.

## Quick start
1. Extract this folder.
2. Open it in VS Code.
3. Install Node.js LTS if needed.
4. Run `npm install`.
5. Run `npm run dev`.
6. Open the local URL printed by Next.js.
7. Review every route and compare it against the master spec before treating it as production-ready.

## What is included
- A clean Next.js 14 / React 18 / TypeScript / Tailwind scaffold.
- Eight routes: Home, About, Services, Features, Blog, Testimonials, Careers, Contact.
- Shared header/footer, section components, motion primitives, and a Canvas-based pixel-arc visual.
- Global design tokens and implementation guidance.
- Copilot rules, QA checklist, and migration handoff.

## Important limitations
- This is a newly authored starting implementation based on the agreed direction, not a pixel-perfect recreation of the original V3 reference. The original reference folder was not available in this session to compare directly.
- The pixel arc is an original Canvas implementation inspired by the selected visual direction, not a verbatim copy of ThreeUI source.
- Logo assets are not bundled because the verified source files were unavailable. A typographic wordmark placeholder is used; replace it with the official Keplor asset when you add it.
- Contact is not connected to a backend. Do not represent it as a working lead-submission system.
- No deployment has been performed.
