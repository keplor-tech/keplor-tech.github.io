# Migration Checklist

- [ ] Back up old folder before replacing it.
- [ ] Extract ZIP and verify root folder.
- [ ] Install dependencies with `npm install`.
- [ ] Start local dev server and inspect pages.
- [ ] Add official logo assets if available.
- [ ] Configure any real contact provider before enabling submission.
- [ ] Run typecheck, lint, build.
- [ ] Review desktop and mobile screenshots.
- [ ] Confirm static export output.
- [ ] Confirm no unintended deployment or remote changes.
